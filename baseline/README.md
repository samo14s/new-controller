# مقارنة عادلة: FOPID مقابل ADRC-FOPID، مع تحسين بـ PSO لتعظيم حدود الاستقرار

نموذج فريزة اللوحة الرقيقة (Du, Liu, Dai & Long, IJMS 274, 2024) بقي كما هو،
وأُزيلت طبقة التحكّم السابقة (μ-synthesis والتأخير) إلى `control_old/`.

```
plant/        نموذج فتح الحلقة (كما زُوّد، بلا تعديل)
control/      المتحكّمان الجديدان + PSO + التقييم
control_old/  الطبقة القديمة (مؤرشفة)
results/      المخرجات: الأشكال، npz، جدول التحقّق، السجلّات
```

## التشغيل

```bash
cd control
python run_pso.py       # 1) تحسين PSO للبنيتين بشروط متطابقة
python run_compare.py   # 2) التقييم الكامل (لوبات، زمني، متانة، ترددي)
python figures.py       # 3) الأشكال
```

## البنيتان

**FOPID** — ‏`C(s) = Kp + Ki·s^(−λ) + Kd·s^(μ)` ‏(5 بارامترات، 16 حالة).

**ADRC-FOPID** — يُعامَل النظام كمكامل مزدوج مضطرب `ÿ = f + b₀u`، ويقدّر مُراقِب
الحالة الممتدّ (LESO من الرتبة 3) الاضطراب الكلّي `f` — وهو هنا يشمل الاقتران
التجديدي المتأخّر وتغيّر `D(x)` على طول الممرّ — فيُلغى بـ ‏`u = (u₀ − ẑ₃)/b₀`،
ويقود FOPID ما تبقّى (7 بارامترات، 19 حالة).

عوامل الرتبة الكسرية مُحقَّقة بمرشّح **Oustaloup** بصيغة **نمطية قطرية**
(دقّة 1.45° طورًا). التحقيق الحالي للـ ADRC مُختبَر مقابل دالة النقل التحليلية:
فرق **4×10⁻¹²**.

## بروتوكول الإنصاف

نفس النموذج والرقعة والحسّاس والإشارة؛ نفس مرشّح Oustaloup ومرشّح مكافحة
الانطواء؛ نفس دالة الهدف والقيود (‏Ms ≤ 2، الجهد ≤ 450 V/N)؛ نفس PSO ونفس
البذور ونفس الميزانية؛ نفس التقييم النهائي (فلوكيه m=200 على نموذج الخمسة
أنماط). الفارق الوحيد هو **بنية المتحكّم** — وعدد البارامترات مذكور صراحة.

## النتيجة الرئيسية (تصميم على نمطين، تقييم على خمسة)

| | بلا تحكّم | FOPID | ADRC-FOPID |
|---|---|---|---|
| متوسط اللوبات (mm) | 0.255 | 2.106 | **3.421** |
| أدنى حدّ عند 4900 (mm) | 0.224 | 1.487 | **2.960** |
| الجهد الأقصى عند 0.6 mm | — | 40.1 V | **17.8 V** |
| Ms | — | 1.997 | **1.881** |

**الانقلاب المهمّ:** FOPID أفضل داخل نموذج التصميم (3.727 مقابل 1.997 mm عند
نمطين) لكنّه يفقد 60 % من حدّه فور ظهور الأنماط 3–5. وADRC-FOPID يفعل العكس:
يرتفع 48 % عند الانتقال إلى خمسة أنماط. المُراقِب يبتلع الأنماط غير المنمذجة
بوصفها اضطرابًا ويرفضها؛ وFOPID لا يملك أيّ آلية لذلك، فتحسين PSO يتخصّص في
نموذج التصميم.
