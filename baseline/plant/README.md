# نموذج محاكاة الفريزة — لوحة رقيقة برقعة بيزوكهربائية

حزمة **بلا أي متحكّم**: النموذج، معاملات القطع، تحليل الاستقرار، والمحاكاة الزمنية. جاهزة لتُركَّب عليها أي استراتيجية تحكّم لاحقًا.

```
python demo.py
```

## الملفات

| الملف | المحتوى |
|---|---|
| `chebyshev_plate.py` | لوحة تشيبيشيف–ريتز (كيرشوف) + رقعة ملصوقة + اقتران بيزوكهربائي + معايرة على تواترات مقاسة |
| `milling_dynamics.py` | معاملات القوى α₃(t) و α₄(t) بتكامل تحليلي، وإحصاءات DᵀD على الحافة |
| `stability_fdm.py` | فلوكيه بالتمييز الكامل (رتبة أولى) — حكم الاستقرار وحدّ العمق |
| `lti_floquet.py` | نفس التحليل بحالة موسَّعة، ويستخرج **تواتر الاهتزاز** من طور المُضاعِف المهيمن |
| `time_domain.py` | تكامل نيومارك بموضع أداة متحرّك وتأخير تجدّدي، ورامبات انخراط وعمق |
| `schedule_im.py` | استخراج تواترات الاهتزاز المتوقَّعة عند أي نقطة تشغيل |
| `demo.py` | خمس عروض متتالية تغطّي كل ما سبق |

## واجهة الاستعمال

```python
from chebyshev_plate import ChebyshevPlate
p = ChebyshevPlate(PX=14, PZ=14)      # حجم الأساس (14 كافٍ ومتقارب)
p.add_piezo_patch()                    # الرقعة QDA60-20-0.7 في الركن السفلي الأيسر
p.calibrate_frequencies([540,1068,2787,3351,4122])   # المعايرة على القياس

p.omega_n        # النبضات الذاتية (rad/s)
p.zeta_modes     # نسب التخميد
p.H_Pe_modal     # اقتران الرقعة لكل نمط (N/V)
p.D_row(x, z)    # شعاع شكل النمط عند نقطة — للأداة أو الحسّاس
```

**حدّ الاستقرار:**
```python
from stability_fdm import stability_limit
L = stability_limit(p, 4900, x_pos=0.0, coeff_mode='time', coeff_scale=1.0)
```

**المحاكاة الزمنية:**
```python
from time_domain import TimeSim
sim = TimeSim(p, rpm=4900, ap=0.3e-3, sign=1.0, n_modes=5, n_sub=164)
r = sim.run(T=None, controller=None, moving=True)   # None = حلقة مفتوحة
```

**لإضافة متحكّم لاحقًا:** مرّر دالة أو كائنًا قابلًا للاستدعاء بالتوقيع `controller(y=..., t=..., k=...) -> u` بالفولت. المخرج يُضرب في `H_Pe_modal` ويُضاف إلى القوى النمطية.

## اصطلاحات لا بدّ من احترامها

**الإشارة.** `coeff_scale` و`sign` يضبطان اصطلاح اقتران التجدّد. القيمة `+1` هي المعادلة (13) كما نُشرت، وهي التي يوافقها الشكل 18 التجريبي في المرجع. المرجع نفسه **غير متسق**: شكلاه 13(b) و14(a) يشيران إلى إشارتين متعاكستين. صرّح دائمًا بالاصطلاح المستعمَل.

**خطوة الزمن.** `n_sub = 82` كافية للحلقة المفتوحة. مع أي متحكّم رنيني استعمل **164 على الأقل**: عند `τ/40` يُظهر التكامل تباعدًا زائفًا لأن تطويل دور نيومارك ≈ 4% عند 1100 Hz يفكّ التوليف.

**الموضع.** امسح **[0, 100] mm كاملة**. التناظر x ↔ lP − x يبدو صالحًا (النمط الأول متناظر والثاني متضادّ التماثل) لكنه مكسور مرّتين: الرقعة ملصوقة لا مركزيًّا (انحراف 9.5–14% على عناصر DᵀD)، والحسّاس مثبَّت عند الركن فيكسر ما تبقّى في أي حلقة مغلقة.

**العمق.** منطقة الاستقرار في الحلقة المغلقة **غير متّصلة في ap**، وجزيرتها لا تلامس الصفر. أي تقييم عند عمق واحد قد يخفي عدم استقرار في القطع الرقيق — وهو ما يحدث فعلًا عند دخول الأداة وخروجها حيث يمرّ العمق عبر كل القيم الصغيرة. قيّم على مجال أعماق، لا على نقطة.

## أرقام مرجعية للتحقّق

بعد المعايرة على [540, 1068, 2787, 3351, 4122] Hz:

| الجداءات D_obs·H | [−0.410, +0.636, −0.084, −1.528, +1.690] |
| المرونة الساكنة عند الركن | 6.50 μm/N (−104.9 dB re 1 m/N) |
| اللارنينات (مدخل القوة) | 742.8 / 2157.5 / 3052.8 Hz |
| حدّ الحلقة المفتوحة عند 4900 rpm | 0.0386–0.0445 mm حسب الموضع |
| ᾱ₄ عند 4900 rpm و0.3 mm | −11 263 N/m (الذروة −139 965، النسبة 12.4) |
| نسبة الانخراط في الدور | 11.8% |
| زمن الممرّ عند 4900 rpm | 20.408 s بتغذية 4.90 mm/s |
| تواتر الاهتزاز عند الشرط S | ~534 Hz (زمنيًّا) — النمط الأول يقود |

نقطة التشغيل المرجعية «S»: **4900 rpm، ae = 0.1 mm، ap = 0.3 mm، fz = 0.02 mm/سن، down milling** — وهي شرط المحاكاة في المرجع، والحلقة المفتوحة تتباعد عندها في 0.107 s.

## صحّة النموذج

مُصادَق على ثلاثة مستويات مستقلّة مقابل المرجع: التواترات ضمن **2.2%**، ومستويات الاستجابة الترددية ضمن **0.3–2.4 dB** على قناتَي القوة والجهد معًا (فيُصادَق مستوى الاقتران البيزوكهربائي نفسه)، واللارنينات ضمن **1.7%** (فتُصادَق أشكال الأنماط بمعزل عن أي معايرة). وتحقّق متقاطع مع تنفيذ عناصر منتهية مستقلّ: 0.0448 مقابل 0.0496 mm عند 4900 rpm.
