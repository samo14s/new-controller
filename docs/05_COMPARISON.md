## المقاييس

| رمز | تعريف |
|---|---|
| $a_{p,\lim}$ | أكبر عمق محوري مستقرّ (تنصيف فلوكيه)، **أدنى قيمة على المواضع** |
| $A_{\max}$ | ذروة الإزاحة عند الحسّاس، ‏$\mu$m |
| $A_{RMS}$ | $\sqrt{\frac1T\int_0^Ty^2dt}$، ‏$\mu$m |
| $T_s$ | زمن الاستقرار للاستجابة **الحرّة** حتى 5 % من الذروة |
| $E_u$ | $\int_0^Tu^2dt$، ‏V²·s |
| $u_{\max}$ | ذروة الجهد، V |
| $\delta_{\max}$ | أكبر تضخيم لمجموعة عدم اليقين تبقى الشهادة صالحة عنده |
| $\tau/\tau_0$ | أوسع مجال تأخير متّصل يبقى فيه العمق الاسمي مستقرًّا |
