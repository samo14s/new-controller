(T3)  the +/-10 % box of Section 3.2 does not contain the reachable set
------------------------------------------------------------------------------

  ARGUMENT A - uses only Table 4 and Section 5 of the paper.
  With M = M0(1+dm), K = K0(1+dk), |dm| <= 0.10, |dk| <= 0.10, the
  attainable frequency ratio obeys
      (f/f0)^2 = (1+dk)/(1+dm)  in  [0.9/1.1, 1.1/0.9] = [0.818, 1.222]
      => f/f0 in [0.9045, 1.1055]  i.e. at most 10.55 % frequency rise.
      mode 1: 540 -> 632 Hz, ratio 1.1704, (f/f0)^2 = 1.3698   OUTSIDE the box   (needs a symmetric bound of at least 15.6 %)
      mode 2: 1068 -> 1162 Hz, ratio 1.0880, (f/f0)^2 = 1.1838   inside  the box   (needs a symmetric bound of at least 8.4 %)

  The paper's own experiment therefore leaves the uncertainty set it
  was designed for.  Nothing in the mu-synthesis certificate applies to
  the machine state at the end of the test campaign.

  ARGUMENT B - the Ritz model says where the perturbation actually goes.
    the eta reproducing the measured +17 % on mode 1 is eta = 0.0755
    (a top strip of 6.04 mm, 7.55 % of the volume);
    it predicts +10.8 % on mode 2, measured +8.8 %.

    at that eta, in the nominal modal basis:
      dM11/M11 = -0.2732   -> mode-1 modal MASS moves 27.3 %, box allows 10 %
      dM22/M22 = -0.2277   -> mode-2 modal MASS moves 22.8 %, box allows 10 %
      dK11/K11 = -0.00038  -> mode-1 modal STIFFNESS moves 0.038 %, box allows 10 %
      dK22/K22 = -0.04788  -> mode-2 modal STIFFNESS moves 4.79 %, box allows 10 %

    The box is UNDERSIZED on mass by 2.7x and OVERSIZED on the mode-1
    stiffness by 266x.  Same nominal +/-10 %, opposite errors.
    Removing material at a free edge is almost pure mass loss: the edge
    carries the modal displacement (kinetic energy) but almost no
    curvature (strain energy).

  CROSS-CHECK, independent of the Ritz model.  If dK = 0 exactly, the
  measured +17 % requires 1/(1+dm) = 1.17^2, i.e.
      dm = -0.2699  (-27.0 %)
  the Ritz model gives dM11/M11 = -0.2732  (-27.3 %).
  Two independent routes, the same number: the mechanism is confirmed.

Consequence for the damping matrix
------------------------------------------------------------------------------
  C_Pr0 = diag(2 zeta_i omega_i).  Even at constant zeta, omega moves with
  eta, so C moves with it:
    mode 1: omega x 1.1710 -> C x 1.1710 at constant zeta  (+17.1 %)
    mode 2: omega x 1.1082 -> C x 1.1082 at constant zeta  (+10.8 %)
  The paper's +/-20 % on C is meant for the uncertainty on zeta itself.
  Once the eta-induced part is included, mode 1 needs 41 % - also outside the box.
